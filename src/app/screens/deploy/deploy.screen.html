Deploy en AWS (EC2) con Docker Compose

Guía práctica para lanzar una instancia EC2 y desplegar con docker-compose.

1. Crear instancia EC2

  1. En AWS Console → EC2 → Launch Instance.
  2. Elegir AMI (por ejemplo, Amazon Linux 2 o Ubuntu LTS).
  3. Tipo de instancia según carga; configurar Security Group (abrir puertos 22, 80, 443 y los 3011-3017 si aplica).

2. Conectar y preparar

ssh -i "mi-key.pem" ec2-user@ec2-xx-xx-xx.compute.amazonaws.com
sudo apt update && sudo apt install -y docker.io docker-compose
sudo usermod -aG docker $USER

3. Subir proyecto y ejecutar

Copiar archivos al servidor (scp o git), luego:

docker-compose up -d --build

Ver logs: docker-compose logs -f

4. Buenas prácticas

  • Usar IAM roles y no claves en el código.
  • Configurar Health checks y monitoreo (CloudWatch).
  • Automatizar con pipelines (GitHub Actions / CodePipeline).

Ejemplo docker-compose.yml

version: "3.8"
services:
  web:
    build: ./web
    ports:
      - "3011:3000"
    restart: always
  api:
    image: myorg/api:latest
    ports:
      - "3012:4000"
    environment:
      - DATABASE_URL=postgres://user:pass@db:5432/app
  db:
    image: postgres:15
    volumes:
      - db-data:/var/lib/postgresql/data
volumes:
  db-data:

Construcción y Contenedores

Tecnologías, puertos y recomendaciones para el entorno de desarrollo.

Tecnologías

  • Docker — Contenerización de servicios
  • Node.js — Backend y scripts
  • NGINX — Proxy reverso y static hosting
  • Postgres — Base de datos relacional

Puertos

Rango de puertos expuestos para microservicios

3011 3012 3013 3014 3015 3016 3017

Ejemplo Dockerfile


FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --production
COPY . .
CMD ["node","dist/index.js"]

docker-compose (resumen)


version: "3.8"
services:
  web:
    build: .
    ports:
      - "3011:3000"
  api:
    image: myorg/api:latest
    ports:
      - "3012:4000"
Consejo: usar .env para puertos y credenciales; mapear volúmenes en desarrollo.
